# 用户故事文档 user_stories.md

## 1. 用户系统
US-01 注册认证：作为一名新用户，我想通过邮箱或手机号注册账号，以便加入论坛并发表投资观点。
验收标准：系统校验邮箱/手机号唯一性；密码加密存储；注册成功后可登录。

US-02 登录鉴权：作为一名已注册用户，我想通过账号密码登录，以便安全访问发帖、评论、收藏等功能。
验收标准：登录成功返回 Token；未登录用户不能发帖、评论、点赞、收藏。

US-03 认证等级：作为一名有专业背景的用户，我想提交从业资格或学历证明，以便获得专业认证标识。
验收标准：用户提交认证资料后进入审核状态；管理员审核通过后显示加 V 标识。

US-04 投资者适当性评估：作为一名专业用户，我想填写风险评估问卷，以便平台了解我的投资风险承受能力。
验收标准：系统记录风险等级；风险等级会影响发帖提示和内容展示提醒。

US-05 个人资料管理：作为一名用户，我想维护头像、昵称、简介、投资经验和关注领域，以便展示个人投资风格。
验收标准：用户可修改资料；昵称不能为空；关注领域可多选。

US-06 隐私设置：作为一名用户，我想控制个人资料的可见范围，以便保护隐私。
验收标准：可设置公开、仅粉丝可见、仅自己可见三种范围。

## 2. 内容系统
US-07 板块浏览：作为一名投资者，我想按 A 股、港股、美股、基金等板块浏览内容，以便快速找到感兴趣讨论。
验收标准：展示板块列表、帖子数量、最新发帖时间。

US-08 动态板块管理：作为管理员，我想新增、修改、删除论坛板块，以便适应市场热点和运营需要。
验收标准：管理员可维护板块名称、描述、排序和状态；普通用户无权限。

US-09 普通发帖：作为一名用户，我想发布文字和图片帖子，以便分享投资观点。
验收标准：标题、正文必填；敏感词触发待审核；发布后进入对应板块。

US-10 长文分析：作为一名研究型用户，我想发布富文本长文并插入图表，以便系统展示更完整的投资分析。
验收标准：支持多段正文、图片链接、附件说明；长文可被设为精华。

US-11 投票调研：作为一名用户，我想发起市场情绪投票，以便收集其他用户对行情的看法。
验收标准：支持多选项；每名用户每个投票只能投一次。

US-12 实时讨论：作为一名盘中用户，我想发布短消息，以便快速交流盘中观点。
验收标准：短消息字数限制 280 字；按时间流展示。

US-13 多级评论：作为一名用户，我想回复帖子或评论，以便进行楼中楼讨论。
验收标准：评论支持父子关系；删除主评论时保留“该评论已删除”提示。

US-14 点赞收藏转发：作为一名用户，我想点赞、收藏或转发内容，以便记录和传播优质帖子。
验收标准：重复点赞会取消；收藏内容进入个人收藏夹。

US-15 附件上传审核：作为一名用户，我想上传 PDF、Excel 研究报告，以便分享更完整的数据资料。
验收标准：附件进入审核队列；审核通过后其他用户可下载。

## 3. 社交与关系系统
US-16 关注粉丝：作为一名用户，我想关注认可的作者，以便持续查看其动态。
验收标准：关注后出现在关注列表；被关注用户粉丝数增加。

US-17 特别关注：作为一名用户，我想星标重要作者，以便优先接收他们的内容提醒。
验收标准：星标用户动态在 feed 中优先展示。

US-18 私信系统：作为一名用户，我想给其他用户发送私信，以便进行一对一交流。
验收标准：支持文本和图片链接；被拉黑用户不能发送私信。

US-19 投资群组：作为一名用户，我想创建投资主题群组，以便组织更小范围的深度讨论。
验收标准：群组支持公开、私密、审核加入；群主可管理成员。

## 4. 信息整合系统
US-20 精华推荐：作为一名普通用户，我想查看编辑精选和算法推荐的优质内容，以便提高信息获取效率。
验收标准：精华内容按热度、质量分、时间综合排序。

US-21 热榜排行：作为一名用户，我想查看每日和每周热门股票、热门基金、热门话题，以便了解市场关注点。
验收标准：系统统计浏览、评论、点赞、收藏数据生成热榜。

US-22 个性化 Feed：作为一名用户，我想根据关注和兴趣获得内容推荐，以便减少无关信息。
验收标准：Feed 根据关注用户、板块偏好、互动历史综合生成。

US-23 全文搜索：作为一名用户，我想按关键词、用户、股票代码搜索内容，以便快速找到历史帖子。
验收标准：支持帖子标题、正文、股票代码、作者昵称检索。

## 5. 管理运营系统
US-24 自动审核：作为管理员，我想让系统自动识别敏感词、重复内容和疑似荐股违规，以便降低人工审核压力。
验收标准：命中规则的内容进入待审；记录命中原因。

US-25 举报处理：作为管理员，我想处理用户举报，以便维护论坛秩序。
验收标准：管理员可通过、驳回、删除内容或处罚用户。

US-26 用户违规处理：作为管理员，我想对违规用户警告、禁言或封号，以便保障社区合规。
验收标准：处罚记录可查询；禁言期间不能发帖评论。

US-27 数据分析：作为运营人员，我想查看论坛活跃度、热门话题和用户参与度报告，以便评估运营效果。
验收标准：提供日活、发帖数、评论数、热门板块、留存趋势统计。
