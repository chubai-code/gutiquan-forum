# 用户故事

## 1. 用户注册与登录

- 作为一名**访客**，我想要**注册账号**，以便成为论坛会员。
- 作为一名**注册用户**，我想要**登录系统**，以便访问论坛功能。
- 作为一名**注册用户**，我想要**修改个人资料**（头像、简介、密码），以便完善我的个人信息。

## 2. 板块浏览

- 作为一名**用户**，我想要**查看所有板块**，以便找到感兴趣的话题。
- 作为一名**管理员**，我想要**创建/编辑/删除板块**，以便管理论坛结构。

## 3. 帖子功能

- 作为一名**用户**，我想要在板块下**发布帖子**（标题+内容+图片），以便分享我的投资观点。
- 作为一名**用户**，我想要**编辑/删除自己的帖子**，以便修正错误内容。
- 作为一名**用户**，我想要**浏览帖子列表**（按发布时间排序），以便发现最新讨论。
- 作为一名**用户**，我想要**查看帖子详情**，以便完整阅读他人的观点。

## 4. 互动功能

- 作为一名**用户**，我想要**评论帖子**，以便参与讨论。
- 作为一名**用户**，我想要**回复他人的评论**（楼中楼），以便进行深入交流。
- 作为一名**用户**，我想要**点赞帖子**，以便表达支持。

## 5. 搜索功能

- 作为一名**用户**，我想要**搜索帖子**（按标题和内容），以便快速找到感兴趣的内容。

## 6. 管理功能

- 作为一名**管理员**，我想要**删除违规帖子和评论**，以便维护社区秩序。
- 作为一名**管理员**，我想要**封禁违规用户**，以便防止恶意行为。
