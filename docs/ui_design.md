# 前端 UI 设计文档 ui_design.md

## 1. 设计目标
界面强调金融社区的信息密度、可读性和合规提醒。首页突出热榜、精选帖子和板块入口；帖子详情突出正文、评论、风险提示和作者信息；个人中心突出资料、成就、关注和收藏。

## 2. 页面结构
### 首页
- 顶部导航：Logo、搜索框、登录/个人中心入口。
- 左侧板块导航：A 股、港股、美股、基金、量化、宏观策略、问答求助。
- 中间内容流：精选、关注、最新、热榜切换。
- 右侧侧栏：热门股票、热门基金、活跃作者、合规提醒。

### 登录注册页
- 邮箱/手机号输入框、密码输入框、验证码占位、登录/注册切换。
- 登录成功后保存 Token 并跳转首页。

### 帖子列表页
- 板块信息头部：板块名称、简介、帖子数。
- 筛选项：最新、最热、精华、长文、投票。
- 帖子卡片：标题、摘要、作者、时间、股票标签、点赞、评论、收藏数。

### 帖子详情页
- 标题区：标题、作者、认证标识、发布时间、板块。
- 正文区：支持多段文本、图片和图表占位。
- 风险提示：投资观点不构成投资建议。
- 评论区：一级评论和楼中楼回复。

### 发帖页
- 板块选择、帖子类型选择、标题、正文编辑器、股票代码标签、附件上传占位。
- 发布前显示合规提示。

### 个人中心
- 用户资料卡：头像、昵称、简介、投资经验、风险偏好。
- 内容统计：发帖数、精华帖、影响力值、勋章。
- 标签页：我的帖子、收藏、关注、粉丝、认证申请。

### 管理后台
- 待审核内容列表：内容摘要、命中规则、风险等级、操作按钮。
- 用户管理：搜索用户、查看违规记录、禁言/封号。
- 数据统计：日活、发帖数、评论数、热门话题。

## 3. 交互设计
1. 搜索框输入股票代码或关键词时显示联想建议。
2. 点赞、收藏按钮采用即时反馈，失败时回滚状态。
3. 发帖时先进行本地校验，再提交后端审核。
4. 管理后台操作需要二次确认，避免误删。
5. 首页内容流支持按关注和兴趣切换。

## 4. 视觉规范
- 主色：深蓝色，体现可信和专业。
- 辅色：绿色表示上涨或正向反馈，红色表示下跌或风险提示。
- 卡片：浅灰背景、圆角、轻阴影，提升信息分组感。
- 字体：正文采用系统默认字体，标题加粗。

## 5. 原型说明
课程设计版本提供可运行前端页面，主要展示首页、登录注册、发帖、帖子详情、个人中心和后台审核入口。部分高级功能采用模拟数据和接口占位，以体现完整系统设计。
