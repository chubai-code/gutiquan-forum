## 阶段完成记录
1. 模块一：完成选题、需求理解、用户故事、交互场景、仓库目录和 README。
2. 模块二：完成架构设计、类设计、数据库设计、UI 设计和 RESTful API 文档。
3. 模块三：完成前后端基础框架、核心业务逻辑、数据库连接和 SQL 脚本。
4. 模块四：完成接口测试、功能测试、异常测试和缺陷修复记录。
5. 模块五：完成本地部署说明、使用说明和课程设计报告整合。

## 协作说明
项目采用模块化分工和集中集成方式。组长负责统一接口规范和代码风格，各成员在完成个人模块后提交到统一仓库。测试成员根据用户故事和交互场景设计测试用例，并将发现的问题反馈给对应开发成员修改。所有 AI 辅助生成内容均由成员人工审查、修改和补充。
